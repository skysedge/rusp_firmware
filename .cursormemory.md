# RUSP firmware notes

## Call-type modes (2026-07)
- `DISABLE_CALL_TYPE_MODES` (default 1): ignore local/ALT switch for dialing.
  Digits append to `dial_buf`; call button (1s hook hold) dials `dial_buf` as typed.
- `KEEP_OLED_DISPLAY` (default 1): do not blank OLED on digit/status timeouts.
- `oled_disable()` is a no-op (does not drop EN_12V).
- Call button: action on **release** (30 ms debounce), not hold duration — one
  action per press (dial / answer / hangup).
- `outbound_call_active`: set after successful ATD; next release hangs up even if
  CPAS still reports ready (0). Cleared on local hangup, NO CARRIER,
  +UCALLSTAT status 6, or CPAS 4→0 after saw_in_call_cpas. OLED: CALLING →
  CALL ENDED. `AT+UCALLSTAT=1` enabled at modem init.
- Call troubleshooting lines go to Serial and `DIAL.LOG` (`BUF`, `DIAL_START`,
  `DIAL_DONE`, `HOOK_*`, `MODE_PHYS`, etc.).
- Pure mode rules: `tools/pulse_monitor/call_mode.py`, `hook_action.py`.

## OLED UI
- Boot: centered `oled_print_status` messages (original style)
- After boot: signal bars (left) + battery icon (right); bottom = number or
  "Ready to dial"; call phase in 8pt centered between icons
- Idle blank: `OLED_IDLE_TIMEOUT_MS` (20s) → `oled_display_off` (0xAE); any
  input wakes (`oled_display_on`). Hangup always; dial/answer only if display
  was already on; C deletes only if already on (wake-only otherwise).
- Charger LED D2 (schematic/PCB): MCP73831 STAT → D2-K; D2-A → R → VBUS.
  **D2 is not connected to any MCU GPIO.** PL5/Arduino D44 (`CHG_STAT`) is
  `unconnected-(U4-PL5-Pad40)` on the PCB. Firmware: INPUT_PULLUP + active-LOW
  so floating D44 does not fake charging. Jumper STAT/D2-K → D44 to enable bolt.
- Warm MCU reset: if `CELL_PWR_DET` already HIGH, skip CELL_ON pulse and
  `+PACSP1` wait (`modem_boot.py`). Also AT-probe before pulse if PWR_DET low.
- After e-ink: `sd_recover_spi()` (CS idle only — no SD.begin) then
  `oled_reclaim_spi()` or OLED stays blank. Never SD.begin after splash.
- Modem: AT-probe before CELL_ON pulse if PWR_DET low — false LOW + pulse
  toggles modem off (`CELL_PWR_DET` timeout).
- Upload baud: Makefile `BAUD=115200` (1M fails urclock sync on this board).
- Battery flash: one solid zigzag glyph; polarity inverted vs overall fill
  level (lit if <50% full, dark if ≥50%).
- E-ink boot splash: precomputed Mandelbrot bitmap `epd_fractal_splash.h`
  (4736 B PROGMEM). Regenerate: `tools/pulse_monitor/gen_epd_fractal_splash.py`
  → also writes `assets/epd_fractal_splash.png`.
- USB plug-in reboot: Mega USB-serial DTR auto-reset into bootloader — hardware
  path, not an intentional firmware reboot. Disable with RESET capacitor /
  cut auto-reset jumper if unwanted.
- Phone number: narrow Iosevka 12pt; display formatted NANP via
  `format_phone_display` / `phone_format.py` — `(234) 567-8901`; dial_buf
  stays raw for ATD
- Call phases from +UCALLSTAT: Dialing (2) → Ringing (3) → In call (0/7);
  Incoming (4); Call ended (6 / NO CARRIER)
- Answered detection: URCs stashed during AT expect (not swallowed); backup
  poll `AT+CLCC` (stat 0 = active → "In call"). CPAS:4 is ambiguous — not used
  for answered UI.
- Flicker: `ui_refresh()` skips redraw when content unchanged
- Signal: `AT+CSQ` → 0..4 bars; battery bandgap fill; tip solid when charging
- Entering digits does not set Dialing — only ATD / UCALLSTAT does

## Dial digits
- Pulse-only spring-return extract; hall is telemetry (`HALL_SEEN`) only.
- Log: `sd cat DIAL.LOG`
